# MapSource Data

This section documents the transfer and management of GPS survey data using Garmin MapSource.

## Applications

- GPS data transfer
- Coordinate management
- Waypoint and track management
- Survey data organization
- Preparation of data for mapping and analysis

## Workflow

1. Collect survey data using Hand GPS.
2. Transfer GPS data to the computer using MapSource.
3. Review and organize waypoints and tracks.
4. Verify coordinate information.
5. Prepare the processed data for further mapping and analysis.

## Output

The processed GPS data provides organized coordinates and survey information that can be used for land mapping, boundary verification, route assessment, and project documentation.
